# 📄 AI-Powered PDF Document Q&A (RAG Lite)

Aplikasi *Retrieval-Augmented Generation* (RAG) ringan berbasis Python dan Streamlit untuk melakukan tanya jawab interaktif dengan dokumen PDF Anda secara lokal dan efisien.

## 🚀 Fitur Utama
- **100% Free & Local Embeddings**: Menggunakan Hugging Face (`sentence-transformers`) untuk memproses vektor dokumen secara lokal di komputer.
- **High-Speed LLM**: Terintegrasi dengan Groq API (`llama-3.1-8b-instant`) untuk menghasilkan jawaban yang cepat dan akurat.
- **Secure API Key Input**: Dilengkapi tombol *trigger* khusus di sidebar untuk mencegah pengiriman API key secara tidak sengaja.
- **Antarmuka Streamlit**: Antarmuka web yang bersih, interaktif, dan mudah digunakan.

## 🛠️ Teknologi yang Digunakan
- **Python** (Bahasa Pemrograman)
- **Streamlit** (Antarmuka Web)
- **LangChain** (Kerangka kerja RAG)
- **ChromaDB** (Vector Database)
- **Hugging Face Hub** (Embeddings)
- **Groq API** (Large Language Model)
